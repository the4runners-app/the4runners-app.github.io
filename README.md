# The 4 Runners — site officiel

**Site : https://the4runners.fr/**  
**Application développée : [Audio2Text sur Google Play](https://play.google.com/store/apps/details?id=com.the4runners.audio2text)**  
**Dépôt Audio2Text : [the4runners-app/Audio2Text](https://github.com/the4runners-app/Audio2Text)**

Ce dépôt publie le site The 4 Runners via GitHub Pages, avec le domaine personnalisé `the4runners.fr` défini dans `CNAME`.

## Positionnement

La page d'accueil présente des prestations de développement de sites web, d'applications web et Android, d'intégration d'IA et d'automatisation. Le contenu est rédigé à la première personne, sans annoncer de délais, tarifs, certifications ou références non vérifiés.

**Audio2Text** est présenté comme une réalisation Android accessible sur Google Play. Les précisions sur les fonctionnalités et la confidentialité restent documentées sur les pages dédiées.

## Pages

- `index.html` : prestations, réalisation Audio2Text, méthode et contact\n- `audio2text.html` : présentation dédiée, fonctionnalités réelles et catalogue Hugging Face en préparation
- `privacy.html` : politique de confidentialité d'Audio2Text
- `delete-account.html` : procédure de suppression de compte Audio2Text
- `assets/site.css` : styles communs et responsive
- `assets/branding/favicon-4r.svg` : identité visuelle de la page d'accueil

## Précautions Audio2Text

La transcription seule ne restitue pas le fichier audio source. La sauvegarde personnelle dépend des fonctionnalités disponibles dans la version Android installée. La sauvegarde cloud Premium est annoncée comme une fonction **en cours de déploiement, pas comme une fonction disponible**. Les informations détaillées restent dans la politique de confidentialité.

## Déploiement

Site statique HTML/CSS et JavaScript léger pour fermer le menu mobile après la navigation ; aucune compilation requise. GitHub Pages publie la branche `master`.

Avant publication : vérifier le menu mobile, la lisibilité, les liens, les conditions d'affichage responsive, l'accès aux pages légales, la validité du sitemap et les balises SEO.
